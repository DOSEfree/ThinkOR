# 产品定义

## 项目名称

IdeaOS-Agent

------

## 产品定位

IdeaOS-Agent 不是通用 AI 助手。

IdeaOS-Agent 是一个面向想法孵化阶段的 Idea Development System。

系统聚焦于把原始、模糊、尚未成形的想法，转换成可理解、可讨论、可执行的计划。

------

## 用户输入

用户提交一个想法。

示例：

“我想做一个 AI 宠物翻译器。”

“我想做一个给儿童使用的学习应用。”

“我想开发一个智慧农业系统。”

------

## 预期输出

系统应生成以下内容：

1. 想法摘要
2. 可行性分析
3. 市场分析
4. 知识缺口分析
5. 资源缺口分析
6. 团队需求分析
7. 相似项目参考
8. MVP 路线图
9. 长期发展路线图

------

## 非目标

v0.1 不构建以下能力：

- 通用聊天机器人
- 个人助理
- 长期记忆系统
- 自主执行 Agent
- 多 Agent 框架
- 社交平台
- 推荐系统

这些方向未来可以评估，但不属于 v0.1 范围。

------

## 产品哲学

每一个想法都是一粒 Idea Seed。

系统存在的意义，是帮助这粒种子更快、更清晰地成长。

系统始终聚焦于想法本身，而不是围绕用户做人格化陪伴。

------

## 工程哲学

优先简单架构。

优先可维护性。

优先可解释性。

避免过度设计。

避免过早优化。

当前目标是验证价值，而不是追求形式上的完美。

------

## 成功指标

用户是否能在一次主要交互中，把一个模糊想法转化为清晰的可执行路线？

如果可以，系统就达到了阶段目标。
