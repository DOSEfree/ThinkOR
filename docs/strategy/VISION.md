# IdeaOS 愿景

## 北极星

帮助想法成长，而不是帮助用户聊天。

------

## 第一阶段目标

构建一个真正聚焦想法孵化的 Idea Development Agent。

输入：

一个模糊想法。

输出：

一组清晰、可解释、可执行的分析结果与路线建议。

------

## 我们不做什么

不做聊天机器人。

不做数字分身。

不做长期记忆。

不做 Agent 人格。

不做社区。

不做社交。

不做内容推荐。

不做多 Agent 编排。

不做自动执行。

------

## 我们只做什么

帮助用户回答：

这个想法是什么？

是否值得做？

它面向谁？

需要什么知识？

需要什么资源？

需要什么团队？

第一步应该做什么？

------

## 核心原则

Agent 服务于 Idea。

不是 Idea 服务于 Agent。

------

## 衡量成功标准

用户输入一个模糊想法后，

系统可以输出足够清晰的结构化结果，

让用户自然产生：

“原来下一步应该这样做。”

的感觉。

------

## 第一阶段结束标准

完成以下核心模块：

- Idea Summary
- Feasibility Analysis
- Market Analysis
- Knowledge Gap Analysis
- Resource Gap Analysis
- Team Requirement Analysis
- Similar Projects
- MVP Roadmap
- Long-term Roadmap

并形成一个可运行、可演示、可继续迭代的 GitHub 项目。

并获得第一批真实用户反馈。

------

## 关于远期想象（非当前范围）

历史上曾设想过 IdeaOS 朝 Idea Network、Idea Graph、Idea Market 方向延伸。

这些只是**远期想象，不是规划，也不是路线**。

明确约束：

- 它们**不属于 v0.1，也不属于 v0.2**。
- **禁止据此进行任何当前设计或架构铺垫。**
- 当前阶段一旦出现向 Network / Graph / Market（以及多 Agent、长期记忆、社区、推荐等）膨胀的倾向，应视为偏离信号并叫停。

唯一被验证的方向，仍是本文件开头那句北极星：**帮助想法成长，而不是帮助用户聊天。**
